# CampusFlow AI 校园时间管家使用说明

本说明从设置学校作息表开始，介绍课表识别、事件校对和 ICS 日历导出的完整操作。

> 网站不要求登录，数据仅临时保存在当前页面中。刷新或关闭页面可能清除尚未导出的内容。

## 1. 设置学校作息表

课程表中常用「第 1～2 节」表示时间。系统需要通过作息表将节次换算为具体时刻。不同学校甚至同一学校不同校区、季节的作息时间都可能不同，应以本校教务处或学生手册最新公布的作息表为准，不要直接照搬示例时间。

### 1.1 获取正确的作息时间

建议按以下顺序查找：

1. 学校教务处网站公布的「作息时间表」。
2. 本学期学生手册或校历。
3. 教务系统、班级通知或辅导员发布的最新版本。

确认每一节课的开始和结束时间，并留意午休、晚课、夏季作息和冬季作息是否有变化。

### 1.2 在网站中应用作息表

进入「上传」页面并选择「作息表」。可以上传作息表截图、PDF 或文本文件，也可以直接按以下格式粘贴：

```text
第一节 08:00-08:45
第二节 08:55-09:40
第三节 10:10-10:55
```

单击「应用作息表」，页面提示已启用相应节次数量后，再上传课程表。也可以在右侧「作息概览」中单击「编辑」，修改后选择「应用」。如需撤销修改，可单击「恢复默认作息」。

### 1.3 检查学期起始日期

在页面右侧「学期起始」区域填写本学期第一周的周一。系统会以该日期为基准，把第几周换算为实际日期。

例如：学校校历规定 2026 年 9 月 7 日是第一周周一，就选择 `2026-09-07`。这里应填写「第一周周一」，不一定是开学报到日或第一次上课的日期。

### 1.4 上传课程表

设置完成后选择与文件相符的入口：

| 入口 | 支持的课程表资料 |
| --- | --- |
| 图片 | JPG、JPEG、PNG、WebP 课表截图 |
| PDF | 教务系统导出的 PDF，或扫描版课表 |
| Excel | XLS、XLSX、CSV 课程表 |

单个文件最大为 25 MB，也可将文件拖入上传区域。应尽量使用原始文件或清晰截图，并完整保留星期、节次、课程名、教室和周次等表头。

> iPhone 的 HEIC/HEIF 图片暂不支持。请先转换为 JPG，或截屏后上传。

### 1.5 等待识别

选择文件后，系统会自动读取内容并生成事件。图片和扫描版 PDF 的识别时间通常长于纯文本；手机网络上传可能需要 1～2 分钟。请在处理完成前保持页面打开。

首次体验时，也可以单击「使用示例」直接查看完整流程。

## 2. 确认识别结果

识别完成后，页面会展示所有已生成的事件，包括：

- 事件名称与类型；
- 时间和地点；
- 重复或周次规则；
- 信息来源；
- 识别置信度。

重点检查低置信度、缺少开始时间或内容明显不完整的事件。确认大致无误后，单击「进入事件编辑」。如需继续识别其他资料，可选择「继续添加来源」。

## 3. 编辑和选择事件

### 3.1 修改普通事件

在左侧事件列表中单击一条事件，然后在右侧修改以下内容：

- 标题或课程名；
- 事件类型；
- 地点；
- 开始时间和结束时间；
- 提前提醒分钟数；
- 备注；
- 考试座位号（仅考试事件显示）。

修改后必须单击「保存修改」。不需要的事件可单击「删除当前事件」。

### 3.2 修改课程规则

课程事件还可以修改：

- 教师和教室；
- 上课星期；
- 开始节次和结束节次；
- 每周、单周、双周等周次规则；
- 起始周和结束周。

修改课程规则前，请再次确认页面顶部的「第一周周一」以及当前作息表是否正确，否则导出的上课日期或时间可能发生偏差。

### 3.3 设置停课日期

「节假日停课」区域用于排除不上课的日期。导出时，落在这些日期的课程会被自动跳过。

- 添加：选择日期，然后单击「添加停课日」。
- 删除：单击已有的日期标签。
- 重置：单击「恢复默认」，恢复系统内置的 2026 年中国法定节假日。

学校校庆、运动会、调休或校历中的其他停课日，需要用户自行补充。若当前学期不在 2026 年，也应按照学校最新校历核对并调整列表。

### 3.4 补充遗漏事件

如识别结果缺少某条通知，可在页面下方「补充一条事件」中输入自然语言，再单击「添加事件」。新事件会加入左侧列表，之后仍可继续修改。

### 3.5 选择需要导出的事件

左侧每条事件前都有复选框。勾选需要写入日历的事件；不想导出的事件可以取消勾选。单击「全选」可一次选择所有事件。

## 4. 导出并导入日历

确认内容后，单击页面右上角的「导出 ICS」。浏览器会下载 `campusflow-events.ics` 文件。

### Apple 日历

在 Mac 上打开「日历」，选择「文件」→「导入」，选择下载的 `.ics` 文件，再选择目标日历并确认。也可以直接打开 `.ics` 文件后完成导入。具体步骤可参考 [Apple 官方说明](https://support.apple.com/guide/calendar/import-or-export-calendars-icl1023/mac)。

### Google 日历

Google 官方说明目前要求在电脑端导入 ICS 文件：

1. 在电脑浏览器中打开 Google 日历。
2. 进入「设置」→「导入和导出」。
3. 选择下载的 `.ics` 文件和目标日历。
4. 单击「导入」。

详细说明见 [Google Calendar 官方帮助](https://support.google.com/calendar/answer/37118)。导入是一次性操作，之后修改 CampusFlow 中的内容不会自动同步到已经导入的 Google 日历。

### Outlook

1. 打开 Outlook 日历。
2. 选择「添加日历」。
3. 选择「从文件上传」，然后选择 `.ics` 文件。
4. 选择目标日历并完成导入。

不同 Outlook 版本的入口略有差异，可参考 [Microsoft 官方说明](https://support.microsoft.com/outlook/import-or-subscribe-to-a-calendar-in-outlook-com-or-outlook-on-the-web)。导入文件不会像在线日历订阅一样自动更新。

不同版本的日历应用菜单名称可能略有差异。导入完成后，请抽查几条课程和考试事件，确认日期、时间、重复规则和提醒均正确。

## 5. 常见问题

### 没有识别到事件

请换用更清晰、裁剪更完整的图片，或改用文本输入。文字内容应至少包含事件名称和明确的日期或时间。

### 图片识别不准确

优先使用原始截图，避免多次转发或压缩。课表应保留星期、节次、课程名和周次等表头；群通知截图应包含完整上下文。

### PDF 上传失败或超时

检查网络后重试。系统会在部分情况下尝试在浏览器本地读取 PDF；如果仍然失败，可复制 PDF 中的文字，改用「文本」入口。

### 课程时间不正确

依次检查「第一周周一」、学校作息表、星期、节次、起止周和单双周规则。这些字段共同决定课程的实际日期和时间。

### 导出按钮提示至少选择一个事件

返回左侧事件列表，勾选至少一条事件后再导出。

### 刷新后内容消失

这是当前版本的正常行为。网站不登录、不写数据库，只在浏览器内存中临时保存数据。建议完成识别后立即校对并下载 ICS 文件。

## 6. 使用建议与隐私提示

- 导入日历前务必人工核对，尤其是考试时间、考场、座位号和作业截止时间。
- 上传前可遮盖学号、身份证号、手机号等与日程无关的敏感信息。
- 同一批资料建议在一个浏览器标签页中连续处理，不要中途刷新或关闭页面。
- 重复导入同一个 ICS 文件可能产生重复事件；再次导入前请先检查目标日历。
- 系统只生成并下载 ICS 文件，不会直接登录或同步用户的日历账户。
